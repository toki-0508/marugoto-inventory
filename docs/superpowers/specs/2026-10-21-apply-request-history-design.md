# 申請フォームの申請履歴 設計

## 目的

利用者が「申請を出したか・出していないか」と、その処理状況を自分で確認できるようにする。

## 決定事項

- 申請フォーム（`apply.html`）のヘッダー右に「履歴」ボタンを置く。
- 押すと全画面パネルが開き、団体名と名前を入力して検索する。フォームの団体名・利用者名が入力済みなら初期値にする。
- 照合は OR 条件。団体名・名前のどちらか一方の入力だけでもよく、どちらかが含まれていればヒットする。
  - 正規化：NFKC、カタカナ→ひらがな、英字小文字化、空白・`、` `,` `・` などの区切り記号を除去。
  - 判定：正規化した入力が、正規化した申請の団体名（または利用者名）に部分一致すればヒット。
  - 両方空なら検索せず「団体名か名前を入力してください」と表示する。
- 結果は申請日時の新しい順にカードで表示する。
  - ステータス（管理画面と同じ表示名・色）：申請中／受け取り待ち／受け取り済／返却完了／登録済み／却下
  - 物品名×個数（購入申請は「購入：物品名×個数」）、申請日時、団体 / 名前
  - 割り当て済みの識別番号、管理者メモ（受け取り場所・日時、却下理由）があれば表示
  - メールアドレスは表示しない
- パネルを開くたびに `Api.getRequests()` で最新を取り直す（申請直後の確認で古いデータを出さないため）。
- 申請完了画面に「申請履歴を確認する」ボタンを置き、入力済みの団体名・名前でパネルを開いて検索する。

## 構成

- `js/request-history.js`（新規）：DOM に依存しない純粋関数だけを置く。
  - `RequestHistory.normalize(text)`
  - `RequestHistory.filter(requests, { organization, name })`：OR 条件で絞り込み、新しい順に並べて返す。
  - `RequestHistory.statusLabel(status)`、`RequestHistory.itemLabel(request)`
- `js/apply.js`：パネルの開閉、取得、描画を担当し、絞り込みは `RequestHistory` に任せる。
- `apply.html`：ヘッダーのボタン、パネルの枠、完了画面のボタン、新しいスクリプト読み込み。キャッシュ回避のバージョン番号を更新する。
- `css/style.css`：既存の `.picker-modal` / `.req-card` / `.status-*` を再利用し、足りない分だけ追加する。

Apps Script は変更しない（既存の `getRequests` を使う）ので、反映は GitHub Pages への push だけで済む。

## エラー処理

- 取得失敗時はパネル内に「申請の取得に失敗しました」と再試行ボタンを表示する。
- 取得中は「読み込み中…」を表示する。
- 0件なら「該当する申請が見つかりませんでした。団体名や名前の書き方を変えて試してください」と表示する。

## テスト
